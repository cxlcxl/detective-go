# 小侦探奇遇记

## 产品宗旨

这是一个以提升孩子学习兴趣为宗旨的微信小程序，希望让孩子对数学、英语等学科产生兴趣，并愿意主动学习。

最终交付给孩子的学习内容和呈现方式是核心，产品形式和功能建设服务于这个目标。后续设计、开发和内容制作都应以此为取舍依据：

- **先打磨内容与呈现，再完善产品功能。** 优先考虑孩子能否理解、是否感兴趣、是否愿意继续探索。
- **内容必须适龄。** 知识难度、语言表达、互动方式和单次学习时长都应符合目标年龄段的认知与身心发展特点，并兼顾孩子已有基础和个体差异，避免超龄灌输和过度训练。
- **可结合中西方教育方式。** 根据具体学习目标，借鉴中西方教育实践中的有效方法，将基础理解与适量练习、动手探索、情境交流和自主提问结合起来；以适龄性和孩子的实际体验选择方法，避免机械套用或简单贴标签。
- **让兴趣发生在学科内容本身。** 通过发现规律、解决问题、实际交流等体验，让孩子感受到数学、英语等知识的趣味和用途。
- **故事与互动服务于学习兴趣。** 侦探冒险是当前采用的呈现方式，可以随内容需要调整；不为了补齐故事或玩法而生硬加入知识题目。
- **以主动学习的意愿检验效果。** 关注孩子是否愿意尝试、主动提问，以及体验后是否还想继续学，不能只看答题正确率或任务完成情况。

每次新增内容、调整呈现或开发功能前，先回答：**它是否适合目标年龄段？它如何帮助孩子对学科产生兴趣，并愿意主动学习？**

## 开发说明

Vue 3 + Vite + uni-app 小程序前端，当前目标平台为微信小程序。

```sh
npm install
npm run dev:mp-weixin
npm run build:mp-weixin
node scripts/check-theme.mjs
```

开发时将 `dist/dev/mp-weixin` 导入微信开发者工具；生产构建产物位于 `dist/build/mp-weixin`。首次导入可使用游客模式，正式真机预览和发布前需要在 `src/manifest.json` 填入自己的微信小程序 AppID。

页面和路由配置在 `src/pages.json`，品牌与主题色在 `src/styles/theme.css`。当前页面使用本地示例数据；语音播放、录音识别、云端存储和教材内容校对尚未接入。
